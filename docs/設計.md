## 3. 結帳頁面 (Checkout Page)
- 為傍晚色系，需與菜單頁面切換自然
- **跳轉方式**：點擊購物車結帳按鈕或頁面下滑直達。
- **內容**：
	- 訂單明細與總金額小計。
	- 外送地址欄位（針對大學生設計：宿舍/校區選擇 + 房號）。
	- 付款方式選擇（餐到付款 Cash on Delivery / 信用卡 Credit Card / 行動支付）。
	- 「Place Order / 送出訂單」互動按鈕（點擊後跳出訂單成功動態彈窗）。
